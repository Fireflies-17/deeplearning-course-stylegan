# Overleaf project

Compile `main.tex` with XeLaTeX. The project is self-contained:

- `main.tex`: report source;
- `main.pdf`: compiled report for direct submission;
- `course_report_style.sty`: local style file;
- `figures/`: all report figures;
- `.latexmkrc`: Overleaf build setting.

Generated files such as `main.aux` and `main.log` are not required for submission.
